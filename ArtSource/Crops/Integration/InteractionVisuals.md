# Root planting and interaction clues

Onion and Radish show the upper half of the bulb above soil during Bulb/Root Forming and Ready. CropVisualStage.soilBurialDepth stores depth in model units; CropDataSO.GetStageOffset applies it only to the planted field view. Depths are Onion 0.1458 / 0.27 and Radish 0.15625 / 0.25. Early stages and detached Harvest models retain their existing positions. The authored crop scale and tile size also scale the burial depth.

WorldInteractionVisuals creates a thin ring under the currently published WorldInteractionPrompt target. Green indicates harvest/pickup or the matching gathering action; yellow indicates another world interaction. Player-owned use/eat/held-item prompts do not draw a ring around the player. Prompt, key input and ring use the same owner and anchor. Hand harvesting now captures that exact crop/field/tile before the approach animation; turning cannot redirect E to a different crop.

Ring readability revision 4 uses a single 0.022-metre stroke at up to 55% opacity. The broad halo and opacity pulse are removed. An enable-time migration also reduces the opacity of an existing runtime manager; discovery-glint settings and target selection remain as configured.

Nearby loose pickups (including dropped/placed items), ready field crops, gatherable resources, ready fruit trees and visible manure piles receive one stationary camera-facing clue per object. Discovery radius remains 12 metres; only the nearest 12 sources receive clues to reduce clutter. Vertical separation is capped at 2.5 metres. Distance visibility is full through 80% of the discovery range and fades at its boundary. A soft 0.85-second twinkle follows opacity 0 to 100% to 0, then stays completely invisible for 4.15 seconds; cycles are staggered across objects. Zero-opacity clues emit no geometry, and no persistent base marker is drawn. No bobbing, size pulsing or companion star is used. Reference half-size is 7 UI pixels at 720p, scaled with screen height and an extra 20% on mobile. Soft thin edges preserve readability. The shared batched mesh and interaction/pickup reach are retained. Readability revision 3 also upgrades the existing runtime manager after script reload.

The Resources material UI/Interaction/WorldInteractionClue retains its shader in builds. Unlit vertex colors keep clues readable at night/rain; ZTest Always and disabled dynamic occlusion culling keep the glints visible through intervening geometry. Only clues use this rendering; item/crop materials remain unchanged. Shadow casting/receiving is disabled. Modal suppression, movement locks, missing cameras and paused gameplay hide the visual batch. Disabled/depleted/collected sources leave the active registries or lose eligibility, preventing lingering clues.

Default automatic mesh outlines on loose pickups are retired in favor of the shared cues. Deliberately assigned custom hint prefabs remain supported. The runtime manager is automatically bootstrapped and also reattached through the prompt's enable path after script reload; no saved Map scene edit is required.

Validation: the real CropDataSO stage/debug code is exercised against all 21 profile schedules, including independently checking the bulb's soil intersection. Interaction target tests exercise range, exact owner/anchor and key consumption. WorldInteractionInputAudit checks all runtime prompt producers. Runtime and Editor sources are compiled with Unity's cached references. These checks are separate from a visual Play Mode check in the running Editor. After import, Stop/Play reloads the complete setup. Nature Paradise > Crops > Validate Applied Crops and Seed Store also checks the imported clue shader/material.
