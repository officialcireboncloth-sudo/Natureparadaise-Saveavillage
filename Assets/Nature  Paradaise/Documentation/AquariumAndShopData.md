# Aquarium UI and dynamic shop product settings

The aquarium interface lives in Resources/UI/Aquarium UI.prefab. Background, selected-fish illustration, tank-layout artwork and each row have image slots; fish images fall back to the actual ItemSO illustration/icon. Layout, typography, panels and controls are authored UGUI elements editable in the prefab. All aquarium sizes use the same interface and their real capacities, with eight rows per page.

Interact with an aquarium using E. The initial list shows stored fish. Masukkan Ikan switches the list to bag fish; select a fish and confirm to deposit one. Ambil Ikan withdraws the selected stored fish. Lihat Koleksi opens the saved fish collection with actual capture counts and largest recorded lengths. W/S or A/D selects fish, Enter deposits, R withdraws, Escape/E closes. Feeding and the five decoration controls continue using the existing aquarium behavior. Transfers retain quality, length and weight and validate capacity before moving items.

FishCollectionService supplies record sizes. Per-catch location and time are not currently stored, so the interface labels them as unrecorded. No mock species, invented capture locations or decorative reference quantities enter gameplay. AquariumService remains the owner of saved tank contents across house scene transitions.

ShopCatalogSO Tabs contain actual ItemSO references, and animal tabs contain AnimalShopOffer data. Add/remove products in these lists. Product Settings (serialized priceOverrides for backward compatibility) provides local price (-1 inherits ItemSO.buyPrice), default quantity, maximum quantity per transaction, delivered quality (0–5 stars) and shop-specific illustration. The catalog inspector's Add Settings For Listed Items creates missing settings without duplicating existing entries. ItemSO still supplies base names, descriptions, images, categories and requirements. Inspector changes update an open shop on its periodic catalog refresh. Quantity settings are purchase limits/defaults, not a finite stock or daily restock system.

Price, amount and quality are enforced by ShopManager as well as the screen. Inventory capacity checks use the exact quality delivered. Successful purchases add that quality to the inventory; failed additions refund gold. Animal prices/icons are edited in the AnimalShopOffer itself; stars describe item quality and do not apply to a living animal. Blacksmith costs remain in Blacksmith Upgrades.asset and house costs remain in the house definition.
