# Dialogue and Shipping Bin UI

DialogueService conversations share a two-character portrait presenter, including existing authored scenes. Player is on the left; the current NPC is on the right. The active speaker is brighter; the listener retains their last expression. Portraits are anchored above a cream dialogue panel and never take space from the text viewport. Missing NPC artwork shows a simple silhouette fallback. Existing quest text, commands, choices and save flags are unchanged.

The player uses Resources/Narrative/Speaker_Player. Each DialogueSpeakerSO has a neutral Portrait and six optional Expressions: Neutral, Happy, Annoyed, Sad, Surprised, Thinking. DialogueNode.emotion selects a preset. Indonesian names and legacy Friendly/Question/Reminder names are mapped to the same presets; unknown/missing presets fall back to neutral. Player nodes use Speaker_Player as speakerOverride. The displayed name and expression follow the node's speakerOverride. Optional conversation playerSpeaker/counterpartSpeaker references support custom players and conversations beginning with a player line; existing conversations infer their NPC automatically.

Player and Mina currently have six transparent portraits each. Mina's hat, hair and clothing follow the actual TFP_Female_Gardener_01A game prefab. The 1536 x 1024 atlases contain six 512 x 512 cells, with bottom-center pivots, no mipmaps or CPU-readable copies, ETC2 RGBA8 on Android and ASTC 6x6 on iOS. No runtime portrait cameras, model clones or per-character Update were added. Add future NPC artwork to that NPC's speaker asset; it will not borrow Mina's identity.

Apply/reimport via Nature Paradise > UI > Dialogue > Apply Character Portraits. Preview Expressions (Play Mode) opens a harmless twelve-line conversation; the same preview is available under F12 > Progres & Aktivitas > Dialog. It does not run quest/reward commands. Portrait art is under UI/Dialogue/Portraits. Full generation prompts and review evidence are in ArtSource/Dialogue/PlayerPortraitApply_2026-10-29. Select Image Slots and Select NPC Portrait Slots remain available for custom artwork.

The dialogue panel uses DialogueTheme cream/ink/sage colors with shared UI typography and rounded surfaces. Continue and close are clickable/touch controls. The first two answer buttons fit fully inside their viewport; additional answers scroll. Long dialogue text scrolls rather than shrinking or truncating. The canvas follows safe-area bounds and adapts to PC, landscape mobile and portrait mobile. Custom panel and portrait artwork remains optional.

W/S or up/down chooses an answer; Enter confirms. Enter/E/Space continues a line without choices. Esc ends conversation. Choice conditions, commands, speaker overrides, quest events, and flags use the existing DialogueService. The service retains its configured clock pause and player movement locks. No relationship values are invented.

Shipping Bin uses the shared chest presenter with its own ShippingBinTheme image slots: Nature Paradise > UI > Shipping Bin > Select Image Slots. Ingredient/item artwork comes from existing ItemSO sprites.

Drag bag to bin to deposit a whole stack; drag back to bag to withdraw using the inventory's existing placement rules. W/A/S/D selects, Tab switches side, E deposits the selected quantity, R takes it back, Shift+E/R transfers a whole stack. Quantity buttons remain available. Unsellable items are visible and cannot be deposited. Valuable sales retain confirmation; Enter confirms and Esc cancels the confirmation before closing.

The bin still merges compatible listings, preserves quality/fish size/unit price snapshots, and pays on daily reset. Its existing unlimited capacity is shown as number of item groups rather than a made-up capacity. Viewing the bin pauses gameplay; close/disable restores its own locks. Buttons are gray with green pointer hover and cyan selected grid outlines.
