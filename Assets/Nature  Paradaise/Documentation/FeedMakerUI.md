# Feed Maker UI

Open using the existing machine interaction. The right-hand panel uses existing FeedMaker recipes, capacity, queue, output, upgrade and save data.

Artwork: Nature Paradise > UI > Feed Maker > Select Image Slots. Assign sprites in FeedMakerTheme; null slots stay empty. Ingredient icons use ItemSO.icon. Poultry and livestock tabs both produce existing universal animal feed. A dedicated machine disables incompatible product tabs.

Buttons are gray normally, green on pointer hover. The active tab has a neutral underline.

Controls: A/D category, W/S quantity, recipe arrows change ingredient recipe, Enter produce, F collect one, Esc close. Production quantities submit existing batches; if materials/capacity run out, the panel reports how many batches were accepted. Processing duration is shown per batch, with original machine level concurrency. Production resumes after closing the paused modal.

An upgrade button retains existing wood/stone/gold costs. Opening, closing or viewing never changes the production/save system.
