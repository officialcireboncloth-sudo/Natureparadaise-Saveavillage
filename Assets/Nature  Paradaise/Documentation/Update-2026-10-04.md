## Cara UI dibuat

Screenshot digunakan sebagai referensi tampilan; UI sesi ini tidak memakai potongan screenshot sebagai panel atau tombol.

UI menggunakan Unity uGUI: Canvas, RectTransform, Image, Button, ScrollRect dan TextMeshPro. Sebagian besar panel gameplay dibuat oleh script saat runtime. Panel/border membulat memakai custom Unity Graphic. Main menu juga memiliki prefab dan setup editor. Background, logo, portrait NPC serta ilustrasi khusus memakai slot Sprite yang dapat diisi melalui Inspector.

Layout visual dapat dibuat tanpa script secara manual pada Canvas/prefab dan diatur lewat Inspector. Implementasi runtime saat ini belum semuanya berupa prefab statis yang tersedia sebelum Play. Data dinamis, drag/drop, pilihan dialog, pause dan transaksi tetap memerlukan script.
