# Image generation source — Cozy modular atlases

Created 31 October 2026 using the built-in imagegen tool. The following production
prompts describe the generated inputs saved in `References`. Native GIMP packs
them into the final atlas, adds palette swatches, and authors an independent
height/normal and URP surface mask. The generated raw inputs are retained so the
packing process can be reproduced without generating images again.
