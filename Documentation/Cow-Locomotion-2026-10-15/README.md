# Map cow and player locomotion — 15 October 2026

The Map uses a raw `TFP_Cow_01F` instance with AnimalGrowthSystem attached, rather than the authored Cow prefab. Its shared Cow Growth Profile still spawned calf stages at 2x and the adult at 3.5x. Profile stage scales now match the authored animals: newborn .55, baby .65, young .8, adolescent .78, adult .9. Young calf bounds are .84 m high and adult bounds 1.26 m. Legacy Map colliders are corrected; AnimalGrowthSystem also fits the live cow collider when growth switches models. No pack mesh is edited.

Player movement is calibrated for the 1.5 m body: walk 1.2 m/s, run 2.4 m/s, sprint 3.4 m/s. Serialized scenes are updated and a versioned Awake migration handles legacy movement settings still loaded in the editor. Keyboard input uses raw axes to avoid coasting after key release. Analog input magnitude is applied once rather than twice.

Walking and running clips were sampled on the actual Generic Mixamo rig at the current player scale. Median backward foot velocity during stance: 1.05937 m/s walking, 2.88722 m/s running. Clip lengths: 1.0 s / .633333 s. Gait choice now uses the Walk/Run/Sprint blend thresholds directly, while the locomotion state speed multiplier follows actual horizontal distance travelled divided by the selected clip's measured reference pace. Sprint reuses the running clip at higher cadence; fatigue/carry penalties lower cadence automatically. Global Animator.speed and action-state timings are not changed. Footstep distances match the measured half-strides (.53 m walk / .91 m run and sprint).

CharacterController collision displacement is used for reported speed, cadence and run activity. Pushing against a wall no longer plays walking/running merely because input requests movement. Generic and Humanoid rig animators can both be selected when valid, avoiding an obsolete wrapper animator.

Play Mode validation uses the actual raw Map cow prefab plus the actual growth profile: young/adult visual bounds and collider heights, resolved player animator, analog half-walk, gait selection, run and sprint travel/cadence, carrying speed/cadence, and wall stop/idle. Results and clip measurements are saved alongside this note. Unity runs in a separate preview project; the main editor is left open. Stop Play and restart to respawn the current cow stage; reopen Map after saving desired scene edits to load its updated serialized collider/speed fields.
